# C-projects

This repository contains short and interactive projects based on the C programming language.

## Project: Rock Paper Scissors Game

This is a simple console-based Rock, Paper, Scissors game written in C. The user plays against the computer, which selects its move randomly.

### Files Included

- `rps.c` – The source code of the game.
- `rps.exe` – The compiled executable (for Windows systems).

### How to Run

#### On Windows
1. Download or clone the repository.
2. If you have a C compiler (like GCC) installed, you can compile the code using:
   ```bash
   gcc rps.c -o rps.exe
